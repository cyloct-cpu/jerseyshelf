## 免费自动翻译

已支持微软 Azure F0、百度通用翻译、DeepL API Free 和 MyMemory 自动接力，后台入口 `/admin/translations`。按配置顺序尝试，额度用完或暂不可用时切换下一家；共用缓存并分别记录额度和等待时间。MyMemory 无需密钥，另外三家需要在后台填写已开通免费账号的密钥。后台继续中文编辑。备份 / 迁移时数据库与 `translation-credentials.key` 必须成套保留，备份脚本已包含该文件。详见 [免费自动翻译使用说明](docs/免费自动翻译使用说明.md)。

订单物流基础查询已接入：前台入口 /track，后台订单详情支持多包裹、商品数量分配、运单更正及操作记录。当前通过承运商官网或 17TRACK 外部链接查轨迹，自动 API 与发货邮件尚未接入。详见 [订单物流查询使用说明](docs/订单物流查询使用说明.md)。

货到付款第一阶段已完成：后续新订单可使用货到付款，后台支持发货资料自动带入、一键复制、通用CSV下单表导出及运单回填、人工签收/代收/回款登记、多包裹代收限制、退回验收入库和待办数量刷新。实际物流API与自动结算尚未接入。详见 [货到付款与物流下单使用说明](docs/货到付款与物流下单使用说明.md)。

订单跟进、商品售后和物流差额闭环已接入：入口 /admin/service，订单详情支持未确认跟进、部分退货、私有图片证据、验收入库、换规格/补发、人工退款及退款抵扣物流待回款。原国家选择保持全部国家；物流商私下转款可登记实际币种。详见 [订单跟进与售后闭环使用说明](docs/订单跟进与售后闭环使用说明.md)。

订单管理与售后对账已整合为订单中心 /admin/orders，统一六项待办及五个工作标签，订单详情按资料、跟进、物流、资金、售后和历史分区；旧售后链接自动跳转。使用说明见 [订单中心整合使用说明](docs/订单中心整合使用说明.md)。

## 2026-10 平台能力升级（KITVAULT 功能移植）

后台新增多管理员与细粒度权限（/admin/staff，8 个权限键 + 登录失败 5 次锁 15 分钟）；在线支付已接入 Stripe Checkout 与 PayPal Orders v2（后台 /admin/payments 配置，订单模式选「正式在线支付」，回调强制验签、未配置密钥直接拒绝，幂等确认收款）；物流履约对接代发 OMS 与 17TRACK API v2.2（后台 /admin/oms，队列自动重试、运单回填 shipments、轨迹每 30 分钟同步）；邮件通知（Resend，付款确认/发货/退款三类多语模板，后台 /admin/email）；Google 登录（后台站点设置配置，id_token 走 JWKS 严格验签）；CSV 批量导入（/admin/import 下载模板、预检后导入、批次留痕）；以图搜款视觉大模型兜底（后台 /admin/image-search 配置 OpenAI 兼容接口，低分时属性转文字检索）；免费翻译源 Google gtx/Lingva 与四源免费汇率轮换（均默认关闭免费翻译源、汇率自动轮换，后台可开）。全部功能有独立开关，关闭即回到原行为。以上各项的取舍与安全修正记录见 [KITVAULT功能移植与双店协同实施方案](docs/KITVAULT功能移植与双店协同实施方案.md)。

双店协同已就绪：本店为商品主库，后台 /admin/sync 生成令牌后，JERSEYDOCK 通过 `/api/sync/catalog`（cursor 增量 + full 全量）拉取商品/分类与媒体清单；媒体按 SHA-256 内容寻址共享，同机共享 media 目录零复制，跨机由消费端按 URL 拉取哈希落盘。消费端脚本位于 KITVAULT 项目 `scripts/sync-from-jerseyshelf.mjs`。新增密钥文件 payment/oms/tracking17/email/oauth/image-search-fallback/catalog-sync-credentials.key 均已纳入备份脚本，须与数据库成套恢复。
