**2026-10-15 更新：百度通用翻译和 DeepL API Free 均已启用并通过真实接口测试，后台状态为“可用”。** 百度保留高级版选项、接力顺序 20 和每月 45,000 字符的本站上限；DeepL 使用已保存的 API Free 密钥、接力顺序 30 和每月 450,000 字符的本站上限。MyMemory 继续作为备用。Azure 的真实连通尚未在本次操作中验证；不能把配置或模拟测试当作真实厂商译文。

在相应卡片填写密钥，设置启用、顺序和字符上限，确认使用对应免费档后保存。然后可点击“单独测试此接口”，使用公开词语“首页”验证；最近接力记录会列出真实成功、额度、权限、限流或网络错误。没有密钥的接口自动跳过。

密钥只在后台填写，不需要发送到聊天。留空保留旧密钥；更换百度密钥时同时填写 AppID。删除密钥时取消启用该接口，并勾选删除后保存。页面和状态接口不会回显密钥。

## 接力方式

默认顺序：微软 → 百度 → DeepL → MyMemory。每个接口的顺序可设置为 1–99，数字小的优先。

1. 同一原文、源语言和目标语言共用一份译文缓存，接口切换不会重复生成已完成译文。
2. 正常任务按顺序尝试已启用、已配置且尚有本站预算的接口。达到某接口上限或收到额度耗尽响应，立即尝试下一家。
3. 无效密钥只暂停相应服务，修改凭据后可继续；不支持某语言只影响该任务的相应接口；暂时网络故障及限流会冷却后再试。
4. 全部服务暂不可用时保留任务，等待最早可重试时间或新配置。不会删除原文、把接口报错展示为译文，或自动购买 / 升级付费服务。
5. “测试接力链路”按正常顺序测试；“单独测试此接口”只调用指定服务。测试与“重试失败任务”都不会清除已用额度或绕过厂商等待时间。

## 额度与账期

总设置默认每天最多请求 20 万字符，各接口再分别执行日 / 月上限。失败请求也保守计入本站请求用量；这些计数代表本站请求，不等于厂商账单。

本站按 UTC 自然日 / 自然月记录。厂商账期、其他项目或同一出口的使用量可能不同。若同一账号还被其他项目使用，请在“本期其他项目已使用的字符数”中填写用量，并将本站上限限制在实际剩余免费额度内。

Azure 必须核对为 F0；百度超额可能计费，不能把高级 / 尊享额度套在标准版账号上，也不要把本站计数当成厂商余额。DeepL 固定免费端点。系统不提供自动充值、升级或切换付费端点。

MyMemory 额度耗尽时按接口返回的等待时间重试。其他服务的远程额度错误最多等待 24 小时再检测；达到本站自然月上限则等下一自然月。所有等待状态、用量与队列均在数据库中持久保存，重启继续。

## 日常编辑与前台

后台继续中文编辑。新增或修改商品、首页、分类、页面与定制模板后，英文任务自动排队；其他语言在访问对应前台页面时按需排队，也可在后台批量生成。导入工具写入的公开内容最迟在一分钟扫描时发现。

人工商品译文优先，其次为该语言内置文案及有效机器译文；缺少译文时暂保留内置英文或原文。翻译完成后刷新前台即可显示。109 项语言菜单不代表每家服务均支持所有语种；百度适配器先支持常用语种，其余交给其他服务。某些语言全部服务仍可能不支持。

只发送公开商品和网站文案。客户姓名、邮箱、地址、订单快照和填写的印字不进入队列。机器译文以纯文字转义输出，不执行返回的 HTML。

## 文件与维护

- `apps/api/auto-translation.mjs`：白名单、共享缓存、队列和接力调度。
- `apps/api/translation-provider.mjs`：四家服务的请求适配、语言映射和响应校验。
- `apps/api/translation-http.mjs`：固定官方 HTTPS 主机、超时、Windows 系统网络兼容；密钥经 stdin 传递给兼容进程，不放进命令参数。
- `apps/api/translation-providers.mjs`：接口顺序、免费用量上限、凭据加密、分接口用量及冷却状态。
- `database/migrations/016-translation-failover.sql`：共享缓存唯一键、分接口用量、状态和接力日志；保留原有缓存和队列。
- `apps/admin/translations.mjs`、`apps/admin/public/translations-admin.js`：中文后台配置与状态显示。
- `tests/auto-translation.test.mjs`、`tests/translation-admin.test.mjs`：隔离数据库、模拟厂商响应、后台鉴权和备份验证，不消耗外部接口额度。

凭据以 AES-256-GCM 加密存入数据库。`translation-credentials.key` 放在数据库同目录，不能提交版本库。正式迁移时数据库和该文件必须成套保留；`scripts/ops/backup.mjs` 现在会同时备份媒体、数据库和存在的翻译 / 汇率加密文件。不要对外公开备份。

`TRANSLATION_AUTO_UPDATE=false` 关闭自动网络请求（测试使用）；后台总开关控制自动排队与处理。任务随网站服务运行，无需另开定时任务。
