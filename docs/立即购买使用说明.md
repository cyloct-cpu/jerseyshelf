# 立即购买与结账

2026-10-15 已完成第一期，本地入口为 http://127.0.0.1:3001/ 。

## 顾客使用

所有商品详情共用两个按钮：白底描边“添加到购物车”和深色“立即购买”。新增和导入商品自动使用同一模板。

选好实际尺码、数量、印字和臂章后，“立即购买”直接进入结账，只结算当前选择，保留原购物车。缺货、超库存或没有可用规格时按钮禁用，旁边显示原因；按钮仍保留“立即购买”名称。

结账页支持国家/地区下拉、收件人、城市、详细地址、邮编、选填电话和最多 1000 字符的订单备注。不同国家采用基础邮编必填规则，当前未接地址自动补全。国家下拉不限制为参考截图的五国，也不表示已经核实每个地区的真实物流覆盖。

桌面左右排列信息表单和订单摘要，手机为单列及可展开摘要。摘要包含商品图、规格、数量、印字/臂章费用、优惠、运费及总价。定制费用已经计入商品金额，不会再次收费。

配送费用继续读取后台的基础运费和免邮件数，满件优惠与多币种沿用现有规则。直接购买仅按本次件数计算优惠，原购物车件数不参与。

“返回修改商品”恢复该购买记录的规格、数量、印字和臂章。每个标签页有独立记录，刷新不会覆盖其他标签页的选择。购买记录与报价有效期为 30 分钟；过期或价格/定制/币种变化后需要重新确认。

未登录可以创建测试订单；从结账页登录或注册后可以回到本次结账。订单备注同时显示在顾客订单页和后台订单详情。

## 店主注意

当前仍是本地测试订单，不扣真实款，后台仍使用模拟付款、发货、取消和模拟退款。真实支付、货到付款、优惠码、礼品卡、地址簿及邮件发送不在此次第一期内。

本次只读核对发现：4,166 件商品中，当前有启用且有库存规格的商品为 0。因此目前实际目录上的购买按钮保持禁用。请在后台“商品管理”核实真实尺码、规格价格、库存，再启用对应规格；不要把“规格待核实”当作可发货尺码。填写完成后前台刷新即可购买，无需重新修改代码。

点击“立即购买”不会扣库存。提交订单时使用事务扣库存，同一购买记录无论刷新、双击或更换请求标识，都最多创建一笔订单。取消或模拟退款沿用原库存恢复规则。

本次未更改原商品、规格、库存、分类、图片关联及运营订单。浏览器测试使用 `storage/qa-buy-now` 数据库副本，仅该副本启用了测试尺码并产生测试订单；临时 3107 测试服务在验收后停止。
