# 本地使用说明

## 当前版本

这是可运行的商城与中文后台基础版本，使用 Node.js 24 和 SQLite，没有第三方运行依赖。

与原实施方案的技术调整：原站与 npm 仓库下载不可达，无法安装 Next.js/NestJS/PostgreSQL 所需环境。为保证当前机器可运行，前台使用服务端 HTML 模板和原生 JavaScript，API 使用 Node HTTP，数据使用 SQLite。目录和业务职责仍分开。SQLite 到 PostgreSQL 的迁移尚未实现；未来迁移需要调整数据访问层和 SQL，不能直接替换数据库文件。

2026-10-14 已采集原站公开目录：4,166 件商品、138 个分类，2026-27 赛季当前快照为 1,406 件。商品来源 ID、分类关联、原站规格和完整图库保存在采集快照中；本地图片导入结果见 `data/manifests/source-import.json`，全量核对结果见 `data/manifests/image-verification.json`。新增商品的运营库存从零开始，应根据自己的实际库存维护。网站整体像素一致性、政策及文章全文仍未完成验收。

## 启动

在项目目录运行：

```powershell
.\启动网站.ps1
```

或使用已安装的 Node.js 24：

```powershell
node apps/api/server.mjs
```

本机商城：http://127.0.0.1:3001/

中文后台：http://127.0.0.1:3001/admin

首次启动自动初始化数据库，并生成 `storage/bootstrap-admin.txt`，其中有管理员邮箱和随机密码。该文件不提交版本库，也不通过网站公开。后台使用同一个登录入口，管理员登录后进入后台，客户登录后进入账户页。

如事先配置 `.env`，可使用 `.env.example` 所列选项。`ADMIN_EMAIL` / `ADMIN_PASSWORD` 只作用于第一次初始化，不会每次重启重设已存在管理员。

启动脚本默认在后台运行网站，端口统一为3001；重复运行会检查已有服务，不再重复启动。日志保存在 storage/server.log 和 storage/server-error.log。需要前台调试时使用 `.\启动网站.ps1 -Foreground`（应先停止已有服务），可按 Ctrl+C 停止。也可使用 `-Port 其他端口` 指定端口。修改服务端代码后需重启；仅修改 CSS/浏览器 JS 时刷新页面即可。

## 后台维护

满件优惠入口：后台“满件优惠”可增删档位、修改件数/金额和开关。默认全站自动 3 件减 5 USD、8 件减 10 USD、10 件减 18 USD，最高档不叠加，可与免邮同时生效。规则和订单维护见 [满件优惠](满件优惠.md)。

实时访问入口：后台“访问统计”显示全站在线、今日访客/访问次数、商品访客/访问次数及商品排行；商品页显示当前真实浏览人数。统计口径见 [实时访问统计](实时访问统计.md)。全部现有商品及后续上品默认保留定制已完成，使用方法见 [商品规格与定制](商品规格与定制.md)；后台“定制模板”统一管理，商品编辑页可选择继承或单品自定义。

### 商品搜索

商品编辑页可填写“搜索关键词”，最多2000字符，支持逗号、空格或换行分隔。前台搜索同时匹配商品名称、描述、多语言译文、SKU、运营关键词、未删除的关联分类及常用中英文别名。例如“法国 / France / 法國”和“阿森纳 / 兵工厂 / Arsenal”可查到对应分类的商品，不要求商品原名称包含中文。多个空格分隔的词同时匹配，例如“法国 球衣”。下架商品不出现在商城搜索结果中，百分号和下划线按普通字符匹配。

搜索页提供大搜索框、实际结果总数和商品网格，支持价格筛选、排序和分页，筛选或翻页时保留关键词。搜索结果数来自本地实际商品，不沿用参考站固定显示数量。批量商品导入可提供 `search_keywords` 字段。

国家队分类的搜索还识别系统语言数据中的各语言国家名称。例如 Deutschland、Germany、德国、ドイツ、독일、ألمانيا对应德国，フランス、프랑스、France对应法国。无需翻译API或在每件商品上重复填写国家译名。国家名称可与其他搜索词组合，例如 `South Korea jersey`；不存在对应商品时仍显示实际的空结果。

### 多语言

商城右上角提供参考图所示的109个语言或文字选项，默认简体中文。选择后在当前页面刷新，保留搜索和筛选参数；语言偏好记忆一年，并应用于后续页面。阿拉伯语、希伯来语、波斯语、乌尔都语、普什图语、信德语、维吾尔语、意第绪语及阿拉伯文字豪萨语使用从右向左布局，管理后台保持中文。语言切换不修改商品价格或支付币种。

常用导航、购物车、商品操作和登录文案使用内置语言包，国家名称使用系统本地化名称；未收录的界面文案回退英文。当前无翻译API，商品名称、描述及商家自定义文案不自动翻译。商品编辑页的“多语言内容”可以分别填写各语言的商品名称和描述，保存后前台优先显示对应译文，空缺内容显示原文。已有商品数据保留不变，译文支持商品搜索。

通过 `/language?lang=en&return=/` 切换并记忆语言，也可以使用 `?lang=en` 临时预览某个语言版本。数据库迁移在重启时自动执行。

1. 媒体库：上传原图，复制生成的 `/media/...` 路径。图片按 SHA-256 去重，保存到 `storage/media`。支持 PNG、JPG、WebP、GIF，单张最大 8 MB；SVG 不接受。
2. 商品管理：编辑名称、网址标识、展示价格、原价、描述、状态、分类和图片顺序。图片区支持直接本地批量上传、素材中心多选、预览、替换、移除、拖动排序和前移/后移。第一张为主图，其他图片可标记为侧面图、尺寸图、内部细节图或参照场景图。支持 JPG、PNG、WebP、GIF，每张不超过 3 MB；尺寸、宽高比例和数量不限，允许重复添加。上传失败可重试，上传未完成或存在失败图片时不能保存，需等待、重试或移除。旧图片保留原顺序，其他图片默认待分类；移除只解除商品关联，不删除媒体库文件。新增数据库迁移在启动时自动执行，服务端修改后需重启网站。
3. 规格与库存：填写真实 SKU、规格名称、规格价格、库存和启用状态。订单按规格价格计费，展示价是商品卡片价格。原站未核实规格默认停用，需自行核实后启用。
4. 分类管理：支持新增、按名称/网址标识查询、编辑、可恢复删除。删除只隐藏分类入口和选择项，商品及关联保留；在“已删除”列表恢复。商品编辑页可搜索分类，点击“新增分类”或“管理分类”在另一标签页维护，返回后点击“刷新分类”，保留当前选择和未保存内容。可维护名称、网址标识、国家队/俱乐部/其他类型、洲或联赛、封面、顺序和首页展示。国家队按欧洲、美洲、非洲、亚洲分组；俱乐部按意甲、英超联赛、法甲联赛、德甲、西甲分组，未列在参考名单中的已有球队保留在其他俱乐部。前台顶部有独立的国家队、俱乐部球队菜单，桌面悬停或点击展开，手机点击展开；后台支持按洲/联赛筛选，商品编辑页按同样的分组选择分类。调整分组后前台重新加载即生效。批量导入可提供 `team_group` 字段，省略时保留已有分组或按参考名单匹配。
5. 首页管理：维护轮播标题、文案、图片及站内链接；维护推荐分类模块。模块按表单中的顺序显示，可移除后重新添加来调整；当前未实现拖拽排序或草稿审批。
6. 页面与文章：纯文本正文支持换行，发布后可访问 `/pages/:slug` 或 `/blogs/:slug`。原站政策正文尚未导入。
7. 设置：站名、Logo、公告、免邮件数、基础运费和客服邮箱。商品和运费基准币种为USD，订单使用顾客所选货币；测试运费默认 10 美元，不代表核实过的原站运费。
8. 订单：模拟付款、物流单号、发货、未付款取消、未发货模拟退款。取消/模拟退款恢复库存，重复执行被拒绝。
9. 客户与订阅：查看新站注册客户、订阅列表并导出订阅 CSV。
10. 操作日志：查看管理员维护动作。

已有规格移除时只停用，不删除；历史订单仍保留成交快照。批量导入默认跳过现有商品，防止覆盖后台修改。

## 本地测试订单

先在后台完善一个真实商品的可用规格和库存，再从商城选择规格、添加购物车、填写收件信息和创建测试订单。页面会明确告知不扣款，后台可继续模拟付款与发货。

金额由服务端计算。订单创建时扣减库存；待处理订单可由管理员取消后恢复库存。目前没有自动释放超时未付款订单的任务，测试后请取消不需要的订单。

## 导入商品

后台“批量导入”支持 JSON 预检和执行。JSON 例子如下；图片必须先进入媒体库，未知规格应明确停用而非编造。

```json
{
  "collections": [
    {"slug":"example-team","name":"球队名称","kind":"club","position":50,"image":""}
  ],
  "products": [
    {
      "slug":"example-product",
      "title":"商品名称",
      "description":"商品说明",
      "price":"17.00",
      "compare_price":"35.90",
      "active":false,
      "images":[],
      "collections":["example-team"],
      "variants":[{"sku":"EXAMPLE-UNVERIFIED","label":"规格待核实","price":"17.00","stock":0,"active":false}]
    }
  ]
}
```

命令行预检及导入：

```powershell
node scripts/import/catalog.mjs data/normalized/catalog.json
node scripts/import/catalog.mjs data/normalized/catalog.json --apply
```

确实需要覆盖现有商品时再加 `--overwrite`。预检不写入；正式导入使用事务，失败会回滚。文件内 slug、SKU 不能重复。媒体导入也可用 `node scripts/import/media.mjs 图片路径`，返回路径后填入商品数据。

当前工具通过公开站点地图和分类分页接口采集公开商品资料，采用固定发布时间排序、每页 40 条及来源 ID 去重。保存原始 HTML、正确排序的分页 JSON、商品清单、原图和 URL/哈希索引，支持继续下载已建立的清单。只读取源站及已核对的 `img.staticdj.com`，不提交原站表单、创建订单或执行下载的脚本。旧的 `site.mjs` 为早期通用采集工具，不作为本次全量商品导入依据。

本次使用本机原有代理读取原站；未修改系统代理或关闭证书验证。其他机器可通过 `CAPTURE_PROXY` 配置代理。详细文件规划、采集方法与原图维护见 [图片采集与分类管理](图片采集与分类管理.md)。

## 备份与维护

```powershell
node scripts/ops/backup.mjs
```

备份保存在 `storage/backups/时间戳/`，使用 SQLite `VACUUM INTO` 生成数据库一致快照，再复制媒体目录。为保证跨数据库和媒体的同一业务时点，备份期间停止后台上传/修改操作。备份含客户/地址等数据，不可公开。

恢复：先停止网站，另存当前 `storage` 数据，再恢复备份中的 `store.sqlite` 与 `media` 到运行目录。恢复数据库时不能混用旧 `-wal`、`-shm` 文件；优先恢复到一个新的目录，再通过 `.env` 指定 `DATABASE_PATH` 和 `MEDIA_PATH`。媒体和数据库必须成套恢复。

源码、采集数据、运行数据库和媒体分别放在 apps、data、storage。更新源码时保留 storage 与 .env。默认只监听本机 127.0.0.1。本轮未执行服务器/域名部署，正式支付、邮件发送、在线客服、角色细分、优惠券和 PostgreSQL 迁移也尚未完成。

### 货币切换与订单

右上角货币菜单提供155个当前货币选项，顾客可独立于语言手动选择，偏好保存一年。货币名称按界面语言显示，列表可按名称或代码搜索，附国旗图标。当前154种货币有可用汇率；VED无报价时不可选择。

商品、定制加价、购物车、运费、价格筛选和新订单均使用所选货币。日元等币种无小数，科威特第纳尔等币种保留三位小数。单价先换算并按最小单位舍入，再乘数量计算小计和合计。后台商品和运费仍按USD维护。

结账报价锁定30分钟，并绑定会话和购物车内容。修改商品价格、数量、运费或货币后须重新确认；历史订单保存币种、汇率、日期及美元基准金额。当前仍为本地测试订单，未接入正式支付。运行期间每24小时更新公开汇率；后台“站点设置”可手动更新，超过7天的汇率不用于新订单。来源和图标许可见 [货币数据说明](../data/currency/README.md)。

### 实时汇率接口与配置

后台“站点设置 → 货币与实时汇率”可选择每日参考模式或实时模式、填写currencylayer密钥、测试连接并保存。尚无API时默认保留参考模式；不把每日参考数据标为实时数据。货币菜单显示当前数据模式。

实时模式每60秒获取一次报价，检查服务响应的实际时间戳。超过2分钟或无效报价不能用于新换算，过期缓存不会自动改用每日参考汇率。启用前必须通过连接和报价时间检查。应使用服务商支持60秒更新的套餐；免费、每日或小时更新套餐不符合该模式要求。服务文档：https://docs.apilayer.com/currencylayer/docs/api-documentation；套餐说明：https://currencylayer.com/pricing。

密钥在服务器端AES-GCM加密保存，不在页面回显或写入操作日志。留空保留原密钥，勾选删除可移除后台保存的密钥。可通过环境变量FX_MODE、FX_API_KEY配置；环境变量中的密钥需在环境配置中移除。备份恢复需要同时保留数据库与storage/fx-credentials.key。实时报价接口通过模拟响应完成测试；没有真实密钥时尚未验证真实服务连接。

### 当前启用的免密钥方案

现已默认启用Frankfurter每日参考汇率。无需注册或密钥，约每24小时同步一次；服务启动时检查距上次成功同步是否超过24小时，超过则自动补更新。后台“站点设置 → 货币与汇率”可保存每日模式、测试Frankfurter连接或立即更新。后台记录最近同步时间（北京时间），货币菜单显示对应汇率的数据日期。服务返回每日参考价，并非秒级交易行情。数据源：https://frankfurter.dev/。

商品详情推荐与最近浏览：后台 → 商品推荐与浏览，可调整两个模块；单品编辑页 → 商品推荐，可设置手动优先与排序。完整说明见 [商品推荐与最近浏览](商品推荐与最近浏览.md)。

语言菜单支持直接搜索：点击页头当前语言，在顶部输入语言名称（例如“英语”“English”“日本語”）或代码（例如 `en`、`zh`）。同时匹配中英文名称和当前界面语言名称，忽略大小写和重音；无结果时显示提示。关闭后重新打开恢复完整 109 种语言列表，点击结果即可切换并记住偏好。
