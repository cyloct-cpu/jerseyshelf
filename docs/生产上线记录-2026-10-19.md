# 生产上线记录

正式商城：https://jerseyshelf.com/

管理后台：https://jerseyshelf.com/admin

## 部署结果

- 雨云香港服务器 `189.24.79.73`，Debian 12。
- 阿里云 DNS：`@` 和 `www` 的 A 记录均指向此服务器，默认线路，TTL 10 分钟。
- HTTP 和 www 地址均以 301 跳转到 `https://jerseyshelf.com/`。
- Let's Encrypt 可信证书覆盖主域名和 www；签发时到期日为 2027-01-17，已配置 certbot 自动续期及 Nginx 重载钩子。
- 独立 Node.js 24.22.0 官方发行包，下载后校验 SHA-256；不修改宝塔面板运行环境。
- 网站目录 `/www/wwwroot/jerseyshelf`，运行用户 `jerseyshelf`，服务 `jerseyshelf.service`，开机自启、失败重启。
- Node 仅监听 `127.0.0.1:3001`，由已有 Nginx 提供公网 HTTPS。Cookie 启用 Secure。
- 代理真实 IP 仅在显式启用且连接来自回环地址时接受，避免登录/注册限流把所有访客视作同一 IP。
- 迁移 4,166 件上架商品、138 个分类、35,019 个媒体文件。使用一致的 SQLite 快照，未迁移本地浏览器会话。
- 线上图片为最长边不超过 1600 像素的同格式网页副本，沿用原图片链接及源文件标识；本地原图未修改。媒体约 8.5 GiB，32 个传输批次均校验 SHA-256。
- 订单模式查询结果为 `cod`，即货到付款。没有在本次部署中接入在线支付或改变订单收款方式。

## 维护

- 查看服务：`systemctl status jerseyshelf`。
- 重启服务：`systemctl restart jerseyshelf`。
- 服务日志：网站目录下 `storage/service.log` 和 `storage/service-error.log`。
- Nginx 配置：`/www/server/panel/vhost/nginx/jerseyshelf.com.conf`。
- 访问日志：`/www/wwwlogs/jerseyshelf/`。
- 生产环境配置：`/etc/jerseyshelf.env`，不包含在本地代码或公共文件中。
- 备份脚本：`/opt/jerseyshelf/backup.sh`；每日服务器时间 03:20 运行，目录 `/var/backups/jerseyshelf/`。数据库使用 SQLite 在线备份，密钥成套保留，媒体以硬链接保存文件集合。已执行首次备份。
- 备份位于同一服务器；日后可增加异地备份。当前不自动清理历史备份。
- 管理员账户沿用迁移数据库中的账户，凭据不记入本文。

线上与本地是独立数据副本。上线后的商品、库存、订单和客户维护应在**线上后台**完成；本地改动不会自动同步。后续发布只更新程序，不能直接用旧快照覆盖生产数据库。

本机部署私钥、数据库快照、传输包和截图均放在已忽略的 `storage/deploy-ssh/`，不要提交或公开这些文件。
