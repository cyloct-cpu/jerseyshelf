# 以图搜款正式上线记录

2026-10-21 已向正式站访客开放：[以图搜款](https://jerseyshelf.com/search?mode=image)。首页顶部搜索框旁有相机入口，文字搜索页可切换“以图搜款”。

## 当前范围

按站点负责人明确选择，先开放全商品主图搜款，详情图继续后台补齐。上线时成功索引 4,155 张去重主图，覆盖全部 4,166 件上架商品，无失败项。初始主图构建耗时约32分钟。

完整图库后台任务已实际开始，目标为当前 34,982 张有效商品关联图片。完成后会原子切换到新索引，无需停止访客搜款或再次发布代码。构建失败继续使用当前主图索引；后续每5分钟检查图库变化，新增或换图增量提取特征。尺寸图排除，商品下架和移除旧图会即时从返回候选中过滤。

输出为相似款候选，不显示“同款概率”。独立顾客实拍验收尚未完成，预览中的跨视角召回仍有限。本次依据负责人在知悉这些限制后明确要求正式上线及分阶段开放的授权发布；没有将试验报告伪记为质量验收通过。

授权记录在生产 `storage/image-search/release-approval.json`，记录发布模式、模型版本、初始索引版本、允许同模型的后续图库更新和已知限制。`independentPhotoAcceptancePassed=false`。模型升级仍需重新核对发布记录，不能自动复用旧模型授权。

## 运行方式

识别模型运行在 `jerseyshelf-image-search.service`，独立于 Node 网站进程。使用仅站点用户可访问、权限0600的 Unix socket，未向公网额外开放模型端口。

识别服务和索引构建服务分别限制 CPU 为单核的80%、内存上限700 MiB；单次上传识别仅执行一个任务，繁忙时返回可重试提示。服务器约2 GB内存，已核对两进程同时运行时仍有约690 MiB可用内存；这是一轮检查结果，不代表长期压力测试通过。

- 网站：`jerseyshelf.service`。
- 私有识别：`jerseyshelf-image-search.service`。
- 全图库及增量构建：`jerseyshelf-image-index.service`。
- 自动检查：`jerseyshelf-image-index.timer`。
- 后台维护：[以图搜款管理](https://jerseyshelf.com/admin/image-search)。可关闭入口、调阈值、查看索引规模和进度、提交重建请求。

生产环境不启用 Node 自带的定时构建进程，使用独立 systemd 索引任务和 timer 执行；后台手动重建写入私有队列，下次任务处理。运行状态保存在 `storage/image-search/build-status.json`。

日志：`storage/image-search/service.log`、`service-error.log`、`index-service.log`、`index-error.log`。图片上传内容不写入这些日志，不永久保留访客原图。模型通过本机私有 socket 接收图像，不向第三方识图服务转发。

## 验证

本地真实模型与搜索语言回归9项通过。正式 HTTPS 冒烟验证25项通过，报告保存于生产 `storage/image-search/production-smoke.json`。

验证包含：全部当前上架商品有索引覆盖、后台鉴权、3个相隔较远商品的主图识别并返回对应款式、公开相机入口、匿名选图页面、英文核心文案、访客真实图片上传与结果、不同会话无法读取他人的查询、价格筛选不回退全库、伪图片拒绝、CSRF保护、文字搜索、购物车及静态资源。

主图样本的服务器推理及检索耗时分别约1,139、468、443 ms；公开上传验证中的模型耗时约754 ms。这些是单次样本，不是生产P95或并发能力保证。验证未创建订单、扣减库存或发送消息。

发布后的浏览器自动取页连续超时，未取得新的正式站截图，因此未将本地预览截图冒充线上验证。正式页面已通过应用打开工具提交打开；界面交互此前在本机相同前端版本跑通，本轮正式域名验证以真实 HTTP/HTTPS 流程为依据。

## 关闭与回滚

优先通过后台关闭“向访客开放以图搜款”，保留文字搜索。若需释放模型资源，再停止 `jerseyshelf-image-index.timer`、`jerseyshelf-image-index.service` 和 `jerseyshelf-image-search.service`。

若必须回滚程序，应恢复上述备份中的源代码和环境配置后重启网站。不要用历史 SQLite 快照覆盖当前生产数据库，以免丢失上线后新增的客户和订单。后台构建任务恢复前应确认模型、预处理版本和当前索引版本一致。
