# 结账国家/地区搜索

更新日期：2026-10-19。

结账页点击“国家/地区”后，下拉面板内显示搜索框。支持按当前页面语言的国家名、简体中文名、英文名及 ISO 两位国家代码筛选，忽略英文字母大小写和重音差异。两位代码精确匹配优先，例如 `US` 只显示美国。清空搜索可恢复全部 249 个国家/地区。

点击结果或按回车确认。方向键切换高亮结果，Escape 关闭菜单，点击外部或 Tab 离开时关闭。搜索文字本身不会修改已选国家，无匹配项时保留原选择，不会提交搜索词。

提交仍使用既有的 country 字段及服务器国家校验；选择国家继续更新邮编和 COD 省州必填规则。JavaScript 不可用时保留原生国家下拉框。

实现文件：

- `apps/storefront/country-picker.mjs`：搜索面板及国家搜索别名。
- `apps/storefront/checkout.mjs`：结账国家字段。
- `apps/storefront/public/store.js`、`store.css`：搜索、键盘交互及响应式样式。
- `apps/storefront/checkout-translations.mjs`：提示语。
