## 维护入口

全站模板：后台菜单“定制模板”，<http://127.0.0.1:3000/admin/customization>。商品编辑页“印字与臂章”管理单品配置；新增入口 <http://127.0.0.1:3000/admin/products/new>。

1. “规格与库存”：每行填写一个尺码、独立 SKU、每件基础价格、实际库存和启用状态。保存后前台显示尺码按钮；停用的规格隐藏，历史订单仍保留。旧的“规格待核实”占位行保持停用。
2. “印字与臂章”默认选择“继承全站模板（推荐）”，可预览印字和臂章。无需逐件开启或重复保存模板。
3. 模板可按分类自动选择，或手动指定俱乐部/国家队。只有国家队关联时使用国家队模板；含俱乐部关联、同时含两种关联或无球队关联时使用俱乐部模板。新商品选择分类时会即时更新预览。
4. 单独维护时选择“单品自定义”：首次从当前模板复制字段，可修改标题、示例、字数、费用及臂章。自定义保存后不随全站模板改变；切回继承后跟随模板，原有单品配置保留备用。
5. 全站模板页先选择俱乐部或国家队模板，再维护字段、臂章名称、图片、费用和启用状态，点击“保存全站模板”。所有继承该模板的商品刷新后更新，单品自定义和历史订单保持独立。全站模板必须保留印字和至少一枚可用臂章。
6. 臂章图片从媒体库复制 `/media/...` 路径；不能填写原站外链或不存在的媒体。后台新增/移除臂章时保持原选项标识，不用改名来复用其它选项身份。

当前默认印字每件加 3 USD；俱乐部模板为联盟臂章、冠军联赛、其它联赛补丁，国家队模板为世界杯臂章、洲际杯臂章、其它联赛补丁，每枚每件加 3 USD。臂章使用已下载的原站图片，支持多选累加费用。风衣、儿童、复古、短裤等商品同样默认保留定制区，尺码仍按各自商品维护。

基础单价 17 USD，填写印字并选一个臂章后每件 23 USD。费用按数量计入订单。当前本店库存仍为 0，请填写实际可售库存后再开放购买；采集时没有复制原站商家的库存数量。

## 购物车与订单

- 同一尺码、同一名字号码和同一组臂章合并数量；不同定制分别保留。
- 同一尺码的所有购物车条目合计检查库存，避免不同定制分别通过校验而超卖。
- 服务端读取当前规格价格及定制加价；浏览器传入的金额不用于计费。
- 商品展示、加购、购物车重算和结账使用同一个生效配置入口。国家队/俱乐部选项标识分开；更换模板后失效的旧臂章不能误当作另一种臂章购买。
- 修改模板价格、名称或图片后，相关未完成的结账报价需重新确认；历史订单保留原内容、模板身份及金额。
- 创建订单保存尺码、SKU、印字、臂章名称/图片和费用快照。后续改价、改名、停用或移除选项不改变历史订单。
- 选项停用后，尚未结账的对应条目标记不可购买；可移除后重新选择。
- 后台订单详情可看到定制内容，供后续制作和发货使用。付款仍采用现有本地测试流程。

## 数据与采集

- `database/migrations/009-product-customization.sql` 增加商品定制配置和订单明细快照字段，服务启动时自动执行。
- `database/migrations/013-default-customization.sql` 增加继承方式与模板选择，已有非空配置保留为单品自定义，空配置自动继承。重复启动不覆盖已有模板和运营设置。
- `apps/api/customization.mjs` 统一解析生效配置、默认模板、后台保存及顾客选择。初始臂章图保存在 `database/seeds/assets/armband.jpg`，新环境初始化媒体库，无需依赖完整采集目录。
- 全站模板存储在 `settings.product_customization_templates`，金额使用美分；后台输入/导入中的定制价格仍以 USD 金额字符串填写。
- 商品 JSON 导入可以省略定制字段以继承；也可提供 `customization_mode: "inherit"`、`customization_template: "auto" / "club" / "national"`。需独立配置时使用 `customization_mode: "custom"` 和原有 `customization` 对象。预检会验证模式、字段和媒体，覆盖导入未指定定制时保留商品现有方式。
- 旧版尚未刷新的新增表单若提交未开启的空定制字段，按继承处理。明确选择单品自定义时仍可设置自己的启用状态。
- `packages/contracts/customization.mjs` 负责配置和顾客选择校验。
- `scripts/import/source-variants.mjs` 仅补齐未管理、无库存的初始占位规格；已有真实规格及后台修改不覆盖。
- `scripts/import/product-options.mjs` 执行来源规格补齐及拜仁款定制配置导入。来源配置为空才填入，重复执行不覆盖管理员配置。
- 原始公开配置及臂章图片保存在 `data/source/shoplazza-2026-10-14/product-customization-source.json`、`customization/patch.jpg`；不执行原站下载的脚本。
- 本次补齐 14 件初始商品的 85 个规格。明细见 `data/manifests/product-options-import.json`，修改前的数据库快照路径也在报告中；该快照未复制媒体，不是完整媒体备份。
