# 网站上线与搜索引擎收录计划

核对日期：2026-10-18。本次仅检查并制定计划，未部署公网、修改收录规则或向搜索引擎提交站点。

## 执行顺序

### 第一阶段：确认正式地址与首发市场

确定正式域名、主域名是否带 www、服务器及域名解析管理方式、默认语言和首批销售市场。面向海外客户时优先 Google 和 Bing；面向中国大陆市场再同时安排百度。

确定唯一正式 HTTPS 地址。其他 HTTP/www 形式跳转到该地址，商品既有 slug 尽量保留。提供明确的生产域名配置，生成 canonical 和站点地图时不使用用户请求中的任意 Host。

验收：主域名方案、默认语言、首批索引语言和域名管理方式明确。

### 第二阶段：完成可在本地开发的 SEO 功能

1. 增加后台 SEO 设置：正式域名、首页标题/摘要、默认语言、允许索引的语言、站长验证配置、测试/正式环境索引开关。
2. 为商品、分类和内容页增加 SEO 标题、摘要及索引开关；未填写时按商品信息生成合理默认值，不把同一段通用描述套给所有页面。
3. 首页、分类、商品添加正确 canonical。商品尺码、排序、币种、营销追踪等参数避免生成大量重复索引页面；分类分页保留可抓取链接及合理的自身地址，不能统一指向第一页。
4. 生成 `/robots.txt` 和 `/sitemap.xml`。站点地图建议拆为商品、分类、内容三类子图，便于核对和维护；4,166 个商品本身并未超过单个地图的 URL 上限。
5. 站点地图只收录正式域名下可公开索引、返回 200 的规范地址。排除搜索结果、购物车、结账、账户、私有订单、后台和错误页面。商品上下架/内容变更后自动同步，lastmod 使用真实有效更新时间。
6. 搜索结果等公开但不希望收录的页面添加 noindex。账户、订单和后台继续依靠鉴权保护。不能把 robots.txt 当作隐私保护，也不能依赖同时禁止抓取的 robots 规则让爬虫读取 noindex。
7. 商品页增加 Product/Offer 和面包屑结构化数据，内容中的币种、价格、可售状态须与对应页面一致；不生成虚构评分或评价。
8. 测试站通过访问控制保护，并保留测试环境的禁止索引设置；生产环境按上线清单放开应索引的页面。

验收：地图可解析、无本地地址/私有链接；页面 canonical、索引规则、标题摘要正确；结构化数据通过检查；原有购物流程及库存功能回归通过。

依据：[Google 站点地图规范](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)、[索引技术要求](https://developers.google.com/search/docs/essentials/technical)、[商品结构化数据](https://developers.google.com/search/docs/appearance/structured-data/product)。

### 第三阶段：准备首批内容与多语言索引

补齐本店联系方式、配送说明、退换货、隐私、条款及常见问题，清除“正文待导入”等占位内容。抽查并完善首批重点商品的准确名称、真实图片、材质、版型、尺码说明、价格和配送信息。优先完善 20–50 个重点商品和主要分类作为验收样本，其他符合条件的商品仍可进入站点地图。

首发以一个主语言加少量已验收语言开展索引。保留用户现有语言选择功能，为可索引的语言提供可直接访问、服务器输出固定语言内容的 URL；检查 Cookie、爬虫未登录访问时的内容一致性。可以先评估沿用现有 `?lang=` 地址，再决定是否需要语言目录，避免无必要地改动商品链接。

真实语言版本分别使用自身 canonical，添加互相对应的 hreflang 和合适的 x-default。不把所有翻译版都 canonical 到默认语言；内容尚未完成的版本不批量列入语言站点地图。

验收：首批语言的商品正文与元数据一致，页面语言稳定，语言关联指向可用页面，所有索引语言经过内容抽查。

依据：[Google 多语言页面说明](https://developers.google.com/search/docs/specialty/international/localized-versions)。

### 第四阶段：正式域名公网部署与上线检查

完成域名解析、HTTPS、后台服务常驻、数据库/图片持久存储、备份与故障日志。在手机网络和外部网络下检查首页、分类、商品、图片、购物车及结账，确认无需登录即可查看的商品返回 200。

检查防火墙/CDN 不误拦搜索引擎；商品图片和公开 CSS/JS 可抓取，私有数据继续受鉴权保护。核对所有绝对地址和重定向都落在正式域名。正式开放时解除公开商品页面的测试 noindex；测试站继续保留保护。

验收：正式域名外网可访问、HTTPS 正常、无误加全站 noindex，地图和商品图片返回正确状态，业务下单流程可使用。

### 第五阶段：在搜索引擎平台验证并提交

**Google 操作步骤**

1. 登录 [Google Search Console](https://search.google.com/search-console/)，添加正式域名资源。
2. 按页面提示在域名 DNS 添加对应 TXT 记录，等待生效后验证。域名资源需要 DNS 验证；如 DNS 暂不方便管理，可评估 URL 前缀资源的文件/标签验证方式，覆盖范围不同。
3. 在站点地图栏目提交正式域名的 `/sitemap.xml`，检查读取状态。
4. 用网址检查工具测试首页、主要分类及代表性商品，确认允许索引、抓取成功、页面内容和规范地址正确；对重要页面申请编入索引，其余页面通过地图和站内链接发现。
5. 使用 [Rich Results Test](https://search.google.com/test/rich-results) 检查商品结构化数据。

验证依据：[Google 所有权验证说明](https://support.google.com/webmasters/answer/9008080)。

**Bing**

进入 [Bing Webmaster Tools](https://www.bing.com/webmasters/)，按平台当前界面完成站点所有权验证并提交同一份站点地图，核对抓取/索引报告。

**百度（需要中国大陆搜索流量时）**

进入 [百度搜索资源平台](https://ziyuan.baidu.com/)，添加并验证实际站点，按账户开放的普通收录入口提交 sitemap 或重要链接。权限、配额和入口以账户实际显示为准，后续再评估新增商品的 API 提交。

依据：[百度平台工具说明](https://ziyuan.baidu.com/college/articleinfo?id=267&page=2)。

验收：所有权验证完成，地图提交状态可读取，代表性网址测试无技术阻塞。提交成功不等于已收录。

### 第六阶段：上线后的持续检查

上线后第 1 周重点检查地图读取、抓取错误、重定向、404/5xx、意外 noindex 和规范地址。第 2–4 周按周检查已发现/已抓取/已索引页面、搜索展现、点击和商品页面问题，按实际原因修复重复、薄弱或翻译不完整的内容。以后保留每周检查节奏，新商品自动更新地图。

这些是运营检查时间安排，不是收录完成承诺。Google 说明满足技术条件仍不保证收录；提交、收录和获得排名是不同阶段。

## 职责与前置资料

- 网站开发部分：SEO 后台、地图、规范地址、索引规则、结构化数据、语言关联和测试报告。
- 公网及账号部分：需要正式域名、服务器访问方式、域名 DNS 管理及站长平台账号配合。账号密码不需要写入本计划。
- 商品经营部分：需要确定首发市场、默认语言、真实商品内容、价格及配送政策。

执行建议：先完成第二、三阶段本地改造；正式域名和服务器就绪后完成公网部署、平台验证和提交。索引发生在公开可抓取之后，也可以在正式推广前提前公开已准备好的页面，具体开放时间由上线安排确定。
