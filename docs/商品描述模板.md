# 商品描述模板

全部商品详情页共用一份图文描述，当前 4,166 件商品及以后后台新增、批量导入、原站采集导入的商品均自动显示，无需逐件复制。

商品描述默认收起。顾客可点击“商品描述”整行或右侧箭头展开，再次点击收起；键盘聚焦标题栏后也可用 Enter 或空格切换。商品专属说明与统一图文模板一起展开、收起，桌面和手机端行为一致。

模板位于 `apps/storefront/product-description.mjs`，按参考图依次展示：库存提醒、全球配送与追踪说明、合作伙伴图、付款后 24–48 小时发货、配送说明、配送保证图、30 天退款保证、WhatsApp 售后文字、安全交易与退货图、仓库说明、团队仓库图及感谢语。红色重点文字与参考一致；图片保留原比例，手机端自动缩小。

WhatsApp 仅显示名称，不包含参考站的电话号码，也没有空号码跳转链接。收到本店号码后，再统一添加到模板即可。

四张原图已保存于 `apps/storefront/public/product-description/`，通过本地 `/assets/product-description/` 地址提供，不依赖外部图片站点。

后台商品编辑页的“商品专属描述”可留空。填写内容会显示在统一模板之前；文字按纯文本处理，多语言译文仍优先用于商品专属描述。全站公共模板使用截图中的简体中文。修改公共模板文件后重启网站，所有商品统一生效。

当前实现通过共用商品页自动应用模板，无需改写商品数据库或在新增、导入时重复保存公共文案。
